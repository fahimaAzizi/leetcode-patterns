# Dynamic Programming

## Pattern Description

> Brief description of Dynamic Programming.

## When to Use

- Overlapping subproblems
- Optimal substructure
- Optimization problems
- Counting problems

## Time Complexity

- Tabulation: O(n) or O(n^2) depending on problem
- Space: O(n) or O(1) with optimization

## Common Mistakes

- Not identifying state correctly
- Wrong transition/recurrence relation
- Forgetting base cases
- Not optimizing space when possible

## Example Problems

- Climbing Stairs
- House Robber
- Longest Increasing Subsequence
- Coin Change
- Edit Distance
- Longest Common Subsequence
