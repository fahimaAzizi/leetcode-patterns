# LeetCode Patterns — 120 Problems

A structured collection of **120 LeetCode problems** solved in C++.

The purpose of this project is not only to solve problems, but to understand the **patterns, algorithms, data structures, and problem-solving techniques** behind them.

---

## 🎯 Goal

Complete **120 carefully selected LeetCode problems** and build a strong foundation in:

- Data Structures
- Algorithms
- Problem-Solving Patterns
- Time & Space Complexity
- C++ Programming
- Technical Interview Preparation

### Progress

**120 / 120 Problems Completed ✅**

- Searching
